# 🩸 BloodLink – Every Drop Connects a Life

**BloodLink** is a blood donation awareness and donor discovery website prototype designed to promote blood donation and connect people with the idea of helping others.

## 🌟 Features

- 🩸 Find donors using blood group and location filters
- 📝 Donor registration form (demo only)
- 🚨 Urgent blood request section
- 🏥 Blood bank directory
- ❤️ Blood donation awareness section
- 📱 Responsive design for mobile and desktop
- ✨ Modern red and white user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
BloodLink/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the BloodLink website.

## ⚠️ Disclaimer

BloodLink is currently a frontend demonstration project.

All donor profiles, blood requests, blood bank information and statistics are fictional demo data. Registration does not save or transmit information. This website is not intended for real emergency coordination.

## 🎯 Project Goal

To promote blood donation awareness and demonstrate how a digital platform could make donor discovery easier.
